<h2>About the game</h2>
This projeect is a recreation of Candy Crush Saga. Candy Crush Saga is a "match three" game, where the core gameplay is based on swapping two adjacent candies among several on the gameboard to make a row or column of at least three matching-colored candies. This solo project was developed in VSC using JavaScript as part of my minigames series where I utilize various resources to remake simple games in order to further my learning as well as to have fun!<br/>

In this Candy Crush clone you can swap colored pieces of candy on a game board to make a match of three or more of the same color, eliminating those candies from the board and replacing them with new ones, which could potentially create further matches. Your mission is to match candies on the game board, which will higher your score.
